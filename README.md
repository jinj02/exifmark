# exify

为Lightroom Classic导出的照片添加简洁的边框和底部参数栏。支持白底、黑底及随背景反色的SONY矢量字标，适用于macOS13及以上、Lightroom Classic13及以上。

| 左侧 | 中间偏右 | 右侧 |
|---|---|---|
| 相机型号 | SONY字标，垂直居中 | 光圈、快门、ISO |
| 镜头型号与实际焦距 | | 拍摄时间 |

## 安装与使用

1. 解压`dist/exify-0.1.0-macos.zip`，将完整的`exify.lrplugin`文件夹放在固定位置。
2. 在LrC中打开“文件→增效工具管理器”，点击“添加”，选择该文件夹。
3. 选中照片，打开“文件→导出”。
4. 在左下角“后期处理动作”中展开“exify”，双击“exify照片卡片”。
5. 使用JPEG格式、关闭HDR输出及文件体积限制，在新增面板中选择背景和边框布局，然后导出。默认三边2%留白、底部8%参数栏，也可选择“仅底部8%参数栏”。

插件可随LrC导出预设一起保存。将当前设置保存为导出预设后，后期处理动作、背景颜色和边框布局会一并保留。旧预设未保存布局时使用三边2%留白、底部8%参数栏。存在其他后期处理操作时，建议把exify放在处理链末尾。

已构建的插件包含Apple Silicon和Intel通用程序及字标资源，使用时无需安装Swift、Python或ImageMagick。保留整个`bin`文件夹及其中的资源包。

## 排版与照片参数

- 横图和竖图默认统一使用“三边2%留白＋底部8%参数栏”：上、左、右各追加照片宽度2%的边框，底部追加照片宽度8%的参数栏。边框颜色随背景选择。
- 可选“仅底部8%参数栏”：照片上方和左右贴边，底部追加照片宽度8%的参数栏。
- 所有比例按EXIF方向校正后的照片宽度计算，分别四舍五入到整数像素。参数栏左侧文字、右侧参数分别距照片左、右边缘1%的照片宽度；字号、字标和间距按照片宽度同比缩放。
- LrC的图像大小设置控制照片区域，保留完整照片内容和原有尺寸。照片为667×1000时，默认边框各13像素、参数栏高53像素，成片为693×1066；选择仅底部时为667×1053。
- 相机和镜头采用LrC目录中的名称；镜头行追加实际焦距。品牌字标固定为SONY。
- SONY字标与右侧参数之间用细竖线分隔，竖线垂直居中并随黑白背景反色。字标和竖线跟随文字实际边缘定位，竖线到文字间隔为照片宽度的1.2%。
- 曝光示例：`f/2.8 · 1/250s · ISO 100`。支持长曝光及小数快门。
- 拍摄时间示例：`2026.10.27 09:41`，保留照片拍摄时钟的日期和时间分量。
- 缺失字段留空。长名称最多缩小至原字号的75%，仍超宽时尾部省略，内容限制在各自区域内。

可见参数来自LrC目录，导出文件移除EXIF后仍能显示。写入成片的元数据仅来自LrC生成的中间图，遵循导出的隐私设置。原始照片与目录中的照片参数保持原样。

## 导出行为

LrC先按照选定的图像大小、锐化、色彩空间和元数据设置生成8位无损TIFF；内置程序按所选布局添加边框和参数栏后，使用ImageIO编码JPEG。JPEG质量数值沿用导出设置，RGB色彩配置随图像继承。最终画布尺寸和EXIF方向同步更新。

JPEG会在目标目录内先写入临时文件，编码成功后原子替换目标文件。文件名、目标路径和已有文件的处理方式交给LrC决定。失败按张报告，其他照片继续处理；取消会在当前照片处理结束后停止后续照片，已完成的JPEG保留。中间文件会清理。

首版支持SDRJPEG。选择其他格式、HDR输出或JPEG体积限制时，面板会显示兼容说明并阻止导出。单张成片限制为2亿像素以内，且宽高均不超过65535像素。

## 从源码构建

需要macOS及支持Swift5.9及以上的Xcode命令行工具。构建过程使用系统框架，源代码无需下载第三方依赖。

```sh
./scripts/build.sh
./scripts/package.sh
```

`build.sh`构建两种架构，将通用程序和资源包写入`exify.lrplugin/bin`，并进行本地临时签名。`package.sh`额外生成安装ZIP。发行包尚未进行Developer ID签名或公证。

源码布局：

```text
exify.lrplugin/       Lua插件、参数格式化、导出调度
renderer/            Swift渲染器、字标PDF和原生验证程序
scripts/             构建、打包、测试及字标资源生成
tests/               Lua测试和独立JPEG解码验证
assets/              原始矢量字标与来源说明
examples/            当前电脑生成的黑白效果样例
```

## 验证

开发测试需要Lua5.1、Python3和Pillow。原生测试直接编译运行，适用于仅安装Xcode命令行工具的环境。

```sh
python3 -m pip install -r tests/requirements.txt
./scripts/build.sh
EXIFY_LUA=/path/to/lua5.1 ./scripts/test.sh
```

测试覆盖两种边框布局、横竖图及画布比例、黑白主题、全部八种EXIF方向、旧请求默认布局、长文字、缺失参数、ICC与隐私元数据、特殊文件名、原子替换、错误及取消处理。实际验收环境与结果见[验证记录](docs/VALIDATION.md)。Intel和旧版macOS的硬件实测仍待补充。
