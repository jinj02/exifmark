# 本地效果样例

`white.jpg`和`black.jpg`由本机LrC15.6使用exify插件实际导出，照片区域为667×1000，信息带高67像素。原始照片来自当前本地目录；样例不打包到插件安装ZIP。

样例沿用上述照片区域重新生成信息带，SONY字标与右侧参数之间增加了随背景反色的细竖线。

字标和竖线按右侧文字的实际边缘贴靠，当前样例中竖线与文字相隔8像素。
