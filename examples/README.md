# 本地效果样例

样例沿用本机LrC15.6导出的667×1000照片区域，通过当前渲染程序重新生成。原始照片来自当前本地目录；样例不打包到插件安装ZIP。

`white.jpg`和`black.jpg`使用默认布局：上、左、右各13像素留白，底部53像素参数栏，成片693×1066。`bottom-only-white.jpg`和`bottom-only-black.jpg`使用仅底部布局，成片667×1053。比例均按照片宽度计算。

SONY字标和细竖线随黑白背景反色，按右侧文字实际边缘定位；当前样例中竖线与文字相隔8像素。

底部左侧文字和右侧参数距照片左右边缘各为照片宽度的1%，667像素宽的照片对应约7像素。
